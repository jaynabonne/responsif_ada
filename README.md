# responsif_ada
## Overview
This is a small project to port bits of my ResponsIF framework from JavaScript to Ada. It's not intended to be a full port, as I'm not sure that code is the direction I want to go in the future. But it does give me a specific project to use to gain experience with Ada with real code.

## Running things
-- Run app
alr run responsif_ada

-- Run tests
alr run test_runner
